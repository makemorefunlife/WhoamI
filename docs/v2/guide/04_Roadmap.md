# 04_Roadmap

## Purpose

Define product evolution stages.

---

# Phase 1

Self Understanding

Features:

* Survey
* Current Self
* Saju Fast Score
* Innate Self
* Gap Analysis
* Gap Preview

Goal:

Help users understand themselves.

---

# Phase 2

Decision Support

Features:

* Integrated Report
* Decision Coaching
* Decision Journal
* Decision Tracking

Goal:

Help users make better decisions.

---

# Phase 3

Relationship Intelligence

Features:

* Friend Analysis
* Partner Analysis
* Compatibility Report

Goal:

Help users understand relationships.

---

# Phase 4

Personal Intelligence Engine

Features:

* Pattern Recognition
* Growth Insights
* Personalized Recommendations

Goal:

Create a continuously improving personal guidance system.
