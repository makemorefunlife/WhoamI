# 10_Deep_Self_Report_UI_Patterns.md

## Purpose

This document defines how Deep Self Analysis should be visually presented.

The goal is not only clarity.

The goal is engagement, recognition, reflection, and action.

The report should feel:

* Easy to scan
* Emotionally resonant
* Shareable
* Memorable
* Insightful

Users should frequently experience:

> "That is exactly me."

Never present a long wall of text first.

```text

↓

↓

```

The visual layer should amplify recognition.

# Narrative Rules

Narrative always comes after visual patterns.

Narrative should:

* Explain why
* Give examples
* Connect patterns to daily life
* Connect identity to behavior
* Connect fear to action
* Connect wounds to recurring patterns

Narrative should never repeat information already visible in the visual component.

---

# Mobile First Rule

All patterns must be readable on a mobile screen.

If a visual pattern requires horizontal scrolling,
it should be simplified.

---

# Shareability Rule

Every major section should contain at least one screenshot-worthy element.

Preferred Screenshot Elements:

* Identity Cards
* Core Fear Cards
* Internal Conflict Cards
* Relationship Loops
* Shadow Pattern Cards
* Narrative Insight Cards
* Growth Dashboards



Action Moment


---

# Design Principle

Human Meaning First.

Narrative Second.

Visual Third.

The report should feel like a conversation with a wise guide.

Not a psychological assessment.

Not a personality test.

Not fortune telling.
