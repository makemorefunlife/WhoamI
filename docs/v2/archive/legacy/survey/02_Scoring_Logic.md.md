# 아하잇츠미 성향 분석 엔진 — 점수 계산 로직 (v3)

## 변경 요약
- 모든 가중치를 1.0으로 동일하게 설정 (Q5만 2배)
- 음수(상쇄) 항목 제거 → 각 축은 독립적으로 측정
- Q1~Q9 모두 "현재 상태" 측정으로 통일
- Q10은 점수 미포함, 결과 문장 보정용으로만 사용

---

## 점수 체계
- 모든 선택지는 -3 ~ +3 범위의 점수를 부여받음

- 그 외 모든 항목은 가중치 1.0으로 동일하게 반영

## 상위 6축 계산 공식 (단순화 버전)

| 상위 6축 | 계산식 |
|---|---|
| 자유성 | 내적자율 + 자극추구 |
| 관계성 | 관계공감 + 인정욕구 |
| 안정성 | 계획구조화 + 자기통제 + 현실실리 |
| 도전성 | 자극추구 + 내적자율 + 사고방식 |
| 통제성 | 자기통제 + 계획구조화 |
| 유연성 | 갈등대응 + 회복탄력 |

※ 모든 항목은 가중치 1.0으로 동일하게 반영
※ Q5(핵심 가치관)만 2배 가중치 적용
※ 각 축은 독립적으로 측정되며, 음수(상쇄) 항목 없음

## 100점 스케일링

최종 점수 = (원시 점수 - 이론적 최소값) / (이론적 최대값 - 이론적 최소값) × 100

※ 이론적 최소/최대값은 9개 문항의 모든 선택지 조합을 실제로 계산해 도출
※ 현재는 추정치 사용 중 (데이터 누적 후 재조정 예정)
