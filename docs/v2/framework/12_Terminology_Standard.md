# 12_Terminology_Standard

## Purpose

Define the official terminology used across Ahaitsme.

This document acts as the single source of truth for naming conventions.

All frameworks, engines, prompts, reports, and future features should follow these terms whenever possible.

---

# Language Rules

## Engine Language

English only.

Used for:

* Code
* JSON
* Database Fields
* Internal Calculations
* Framework Axes
* Prompt Variables
* AI Processing

---

## User Language

Localized.

Displayed in the user's selected language.

Examples:

Current Self → 현재의 나

Innate Self → 본래의 나

Decision Journal → 결정일기

# Naming Principles

Use official English terms internally.

Use the same official terms throughout:

* Guide
* Framework
* Survey
* Saju
* Gap
* Decision
* Relationship
* Reports
* Prompts

Avoid creating alternative names for the same concept.

---

# Future Expansion Rule

New systems should map into existing terminology whenever possible.

Create new terminology only when absolutely necessary.
