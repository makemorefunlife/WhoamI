# 10_Human_Framework

## Purpose

The Human Framework is the unified behavioral model used across Ahaitsme.

All data sources are translated into the same human-centered language before analysis.

Supported sources include:

* Survey Results
* Saju Analysis
* Relationship Analysis
* Decision Journal
* Future Behavioral Models

The framework enables direct comparison between Current Self and Innate Self.

---

# Primary Axes

## autonomy

Degree to which a person follows internal values, self-direction, and personal choice.

Korean Reference: 자율성

---

## connection

Degree to which a person values belonging, emotional connection, and relationships.

Korean Reference: 관계성

---

## stability

Degree to which a person seeks security, predictability, and consistency.

Korean Reference: 안정성

---

## growth

Degree to which a person pursues development, challenge, exploration, and improvement.

Korean Reference: 성장성

---

## control

Degree to which a person prefers planning, structure, organization, and self-management.

Korean Reference: 통제성

---

## adaptability

Degree to which a person adjusts effectively to uncertainty, change, and new situations.

Korean Reference: 유연성

# Framework Design Philosophy

The Human Framework is designed to provide a stable behavioral model that can be shared across all Ahaitsme systems.

The framework should remain consistent across:

* Survey
* Saju
* Gap Analysis
* Decision Analysis
* Relationship Analysis

Primary Axes represent the most stable human behavioral dimensions.

Secondary Axes provide additional context and interpretation.

Future systems should map into the Human Framework whenever possible rather than creating new frameworks.

This ensures that all user data can be compared and analyzed through a common language.

---

# Core Principles

* Current Self and Innate Self are measured using the same framework.
* Saju data must be translated into the Human Framework.
* Relationship data must be translated into the Human Framework.
* Decision Journal data must be translated into the Human Framework.
* All future models should use the same framework whenever possible.
