# 04_Survey_Output_Schema

## Purpose

Define the official output structure of the Survey System.

This document acts as the official Current Self schema.

All future systems must reference this structure.

Including:

* Gap Engine
* Report Engine
* Decision Engine
* Relationship Engine

---

```json
{
  "profile_type": "current_self",

  "primary_axes": {
    "autonomy": 0,
```

# Personalization

Generated from Q10.

Not used for scoring.

Used only for:

* report examples
* wording selection
* coaching context

```json
{
  "primary_concern": "career"
}
```

Allowed Values

* money
* relationship
* health
* career
* other

# Current Self Summary

Generated after scoring.

Structure

```json
{
  "summary": {
    "title": "",
    "short_summary": "",
    "strengths": [],
    "watch_points": []
  }
}
```

Example

```json
{
  "title": "Balanced Growth Planner",
  "short_summary": "You currently balance stability and growth while maintaining a structured approach to decisions.",
  "strengths": [
    "Long-term thinking",
    "Consistent execution"
  ],
  "watch_points": [
    "Difficulty relaxing",
    "Overplanning"
  ]
}
```

# Versioning Rule

The Current Self schema should remain stable whenever possible.

Future systems should extend the schema rather than replacing it.

Breaking changes should create a new version.

Examples

* current_self_v1
* current_self_v2
