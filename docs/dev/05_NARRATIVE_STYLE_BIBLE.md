> **Single narrative SSOT:** `docs/product/05N_Ahaitsme_Narrative_Style_Bible.md` (v2.0).

## What this document was

The "Invariant Core" (Rev. 7): a technically rigorous narrative rulebook — narrator persona, epistemic language contract, domain register dials, address law, a severity ladder cross-referenced against evidence tiers, golden examples per domain, and a lexicon/terminology-control system with an amendment gate.

It existed in parallel with `docs/product/05N_Ahaitsme_Narrative_Style_Bible.md` ("v1.0"), which covered largely the same ground — narrator identity, evidence-aware writing, dignity, advice architecture — but in warmer prose, with fuller sections on humor, metaphor, bilingual register, a QA rubric, and a human-editorial-review pass that this document lacked. Two documents claiming the same authority is exactly the kind of duplication that causes agents (and humans) to pick different voice laws for the same task — flagged as the highest-risk documentation remnant in `docs/product/README.md`, `09_Product_and_Design_Intent_Package.md` §6.3, and `10_Design_IA_Canonicalization_Refactor_Plan.md` §1.2/§10.3/§10.1.
