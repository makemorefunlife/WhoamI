## 배운 점 / 결정

- Vercel `NEXT_PUBLIC_*` 환경변수는 설정 시점/스코프(Production vs Preview)가 어긋나기 쉬워 조율 비용이 큼 — 임시/실험적 on-off 스위치는 환경변수보다 **코드 상수**(커밋 = 실제 동작)가 이 상황엔 더 적합했음.
- 결제사가 완전히 막힌 상품에 "결제창 없는 즉시 지급"을 임시로 넣을 땐, 매출/테스트 데이터와 섞이지 않게 `credit_lots.source`(기존 `'promo'` 값 재사용) + `grant_credit_lot_scoped`의 시장 스코프(`en-US`)로 KR 쪽과 완전히 분리하는 게 기존 신용 엔진 구조와 가장 잘 맞았음.
- "안내창이 생략됐다"는 보고를 받았을 때, 내 diff가 그 분기(안내창 띄울지 말지)를 건드렸는지부터 git log로 먼저 확인한 게 — 실제로는 무관한 "이미 보유한 이용권" 기존 로직이었음을 빠르게 가려냄.
